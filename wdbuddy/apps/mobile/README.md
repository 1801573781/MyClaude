# WDBuddy Mobile（占位）

多端联动端：配套手机 APP 与微信小程序。

## 能力（对齐桌面端 FR-20）

- **扫码绑定**：扫描桌面端二维码完成设备配对
- **远程下发**：手机端向桌面端下发自然语言任务指令（需桌面端在线）
- **结果通知**：桌面执行完成后经推送通道向手机发送结果通知
- **离线提示**：桌面端离线时，下发指令返回明确的"桌面端离线"错误

## 技术规划

- 微信小程序（下发指令 + 接收通知）
- React Native / 原生 APP（后续版本）
- 与云端 `/v1/remote/commands` 接口交互（见 apps/server）
